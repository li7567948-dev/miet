# Лабораторная работа 1: SORT + POISK
Основание: расписание лабораторных работ и «Лабораторная работа №1.pdf», стр. 2–9.

## Варианты
| Раздел | Вариант 3 | Вариант 8 |
|---|---|---|
| SORT | Метод Шелла: 2000, 5000, 6800 | Простая вставка: 1200, 2000, 7500 |
| POISK | Поиск по бору: 2000, 5000, 6800 | Поиск хешированием: 1200, 2000, 7500 |

## Исходные файлы
- variant3_shell.cpp — SORT, вариант 3
- variant8_insertion.cpp — SORT, вариант 8
- poisk_variant3_trie.cpp — POISK, вариант 3
- poisk_variant8_hash.cpp — POISK, вариант 8

**Visual Studio:** создайте ЧЕТЫРЕ отдельных консольных проекта C++17; в каждом должен быть только один файл с main(). Не добавляйте все четыре файла в один проект. Иначе появится ошибка LNK2005 / LNK1169.

## Исследование
В программах SORT: 5 опытов на размер, случайные / отсортированные / обратно отсортированные массивы, время, сравнения, перемещения и CSV.
В программах POISK: 5 опытов на размер, N заведомо присутствующих и N отсутствующих ключей; отдельно измеряются построение структуры и время всех 2N запросов; результаты сохраняются в CSV. Для сравнения одного поиска можно разделить search_us на 2N.

Это самостоятельные программы для изучения методов; результаты отличаются от показаний учебных EXE. PDF требует тестирования в Sort.exe, Winsort.exe и Poisk*.exe. Если преподаватель разрешил не использовать учебные программы, следует подтвердить, что он также принимает альтернативные измерения.

## Конспект к лабораторной работе (обязателен)
1. Цель: изучение методов сортировки и поиска, экспериментальная оценка времени.
2. Метод Шелла: сортировка вставками с уменьшающимся шагом, последняя итерация с шагом 1.
3. Простая вставка: вставка каждого следующего элемента в упорядоченную часть массива; худшая сложность O(N^2).
4. Бор: префиксное дерево; для целых чисел используются десятичные цифры, поиск зависит от числа цифр ключа.
5. Хеш-таблица: вычисление индекса хеш-функцией, разрешение коллизий методом цепочек; среднее время поиска близко к O(1), худшее O(N).
6. Сравнение: скорость зависит от N, порядка исходных данных, реализации и оборудования.
7. Вывод: заполнить после собственных измерений и сравнения таблиц.
