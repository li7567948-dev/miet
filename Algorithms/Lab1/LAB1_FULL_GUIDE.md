# Лабораторная работа №1 — единый проект C++17

Основной исходный файл: **lab1_all.cpp**. В нём одна функция `main()`; отдельные исходные файлы вариантов удалены. Для Visual Studio создайте **один** проект «Пустой проект» C++, добавьте только `lab1_all.cpp`, установите стандарт C++17 и запустите Ctrl+F5.

## Реализованные разделы

- SORT, вариант 3: метод Шелла, N = 2000, 5000, 6800.
- SORT, вариант 8: простая вставка, N = 1200, 2000, 7500.
- POISK, вариант 3: поиск в цифровом боре (требует сверки с исходной таблицей вариантов задания по поиску).
- POISK, вариант 8: поиск в хеш-таблице `std::unordered_set` (требует сверки с исходной таблицей вариантов задания по поиску).

Меню: 1/2 — сортировка; 3/4 — поиск; 5 — все опыты; 0 — выход.

## Измерения

SORT: для каждого N пять запусков на случайных, упорядоченных и обратно упорядоченных массивах. Программа измеряет время в микросекундах, считает сравнения и перемещения, проверяет правильность сортировки, выводит средние значения и сохраняет `sort_variant3.csv` / `sort_variant8.csv`.

POISK: пять запусков для каждого N, проверки присутствующего и отсутствующего ключа; результаты сохраняются в `poisk_variant3.csv` / `poisk_variant8.csv`. Время поиска не включает построение структуры данных. Показатели отражают одиночный запрос, а не серию из N запросов.

CSV-файлы создаются **после запуска программы на компьютере студента** в текущем рабочем каталоге. Не выдавайте примерные значения за измеренные.

## Проверка перед сдачей

1. В Visual Studio должен быть ровно один исходный файл с `main()`: `lab1_all.cpp`.
2. Выполнить пункт 5, проверить строки `sorted=YES` и `correct=YES`, наличие четырёх CSV.
3. Проверить точное соответствие POISK вариантам 3/8 по оригинальному заданию (в имеющемся описании таблица не подтверждена).
4. Если преподаватель требует отчёт, графики или конспект, оформить их отдельно на основе реальных измерений. По сообщению студента, использование учебных EXE не обязательно.

## Вывод (общий, без выдуманных измерений)

Метод Шелла выполняет сортировку вставками с последовательно уменьшающимся шагом. Простая вставка имеет квадратичную сложность в неблагоприятном случае и линейную при уже упорядоченном массиве. Время выполнения зависит от размера и начального порядка элементов; экспериментальные численные выводы делаются только по результатам запуска.
