Лабораторная работа №1. Часть 1. Сортировка.
Вариант 3: метод Шелла, N = 2000, 5000, 6800.
Вариант 8: простая вставка, N = 1200, 2000, 7500.

Компиляция (C++17):
g++ -std=c++17 -O2 variant3_shell.cpp -o variant3_shell
g++ -std=c++17 -O2 variant8_insertion.cpp -o variant8_insertion

Запустить обе программы отдельно. Каждая генерирует массив
псевдослучайных целых чисел, сортирует его, измеряет время
и проверяет правильность сортировки.

ВНИМАНИЕ: методические указания дополнительно требуют
исследовать методы в Sort_new.exe и Winsort.exe и записать
результаты в таблицы. Без этих программ реальные измерения
их работы нельзя достоверно заполнить. Время зависит от ПК.

Вывод:
Метод Шелла ускоряет сортировку за счет сравнения элементов
с уменьшающимся шагом. Простая вставка последовательно
вставляет очередной элемент в отсортированную часть массива.
Оба алгоритма корректно сортируют массив по возрастанию.
