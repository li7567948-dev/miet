Лабораторная работа №1, часть 1 / 实验1 第一部分
==================================================
Вариант 3 / 第3变体: метод Шелла / 希尔排序
Файл: variant3_shell.cpp; N = 2000, 5000, 6800.

Вариант 8 / 第8变体: простая вставка / 简单插入排序
Файл: variant8_insertion.cpp; N = 1200, 2000, 7500.

ВАЖНО / 重要：
Каждый файл — самостоятельная программа с функцией main().
Создайте ДВА ОТДЕЛЬНЫХ проекта Visual Studio.
每个文件都是带 main() 的独立程序，必须分别建立两个 Visual Studio 项目。
如果把两个 .cpp 放在同一个项目里，会出现 LNK2005/LNK1169 重复定义错误。

Visual Studio / 俄语界面操作：
1. Файл → Создать → Проект → Консольное приложение C++.
   文件 → 新建 → 项目 → C++ 控制台应用程序。
2. Создайте проект Variant3; добавьте только variant3_shell.cpp.
   创建 Variant3 项目，只添加第3变体源代码，移除模板自带的 main.cpp。
3. Создайте второй проект Variant8; добавьте только variant8_insertion.cpp.
   另外创建 Variant8 项目，只添加第8变体源代码。
4. Используйте C++17; Ctrl+F5 для запуска.
   设置 C++17，按 Ctrl+F5 运行。

Компиляция в терминале / 命令行编译：
g++ -std=c++17 -O2 variant3_shell.cpp -o variant3_shell.exe
g++ -std=c++17 -O2 variant8_insertion.cpp -o variant8_insertion.exe

Программа каждого варианта исследует семь методов сортировки:
простая вставка, слияние, Шелл, простой выбор, Хоар,
бинарная вставка, шейкерная сортировка.
每个程序分别测试7种排序：直接插入、归并、希尔、选择、快速、
二分插入、鸡尾酒排序。

Для каждого N используются случайный, упорядоченный и обратно
упорядоченный массивы. Измеряются время, сравнения, перемещения.
针对每个指定 N 测试随机、升序、降序数组，记录时间、比较次数、
移动次数和正确性。每个程序输出63条测量记录。

Файлы результатов создаются при запуске:
variant3_results.csv и variant8_results.csv.
运行后生成两个 CSV 文件，数据取决于实际电脑运行情况。
