Лабораторная работа №1 — Часть 1 / 实验1 — 第一部分
=================================================

Один исходный файл: lab1_part1.cpp
只有一个 C++ 源代码文件：lab1_part1.cpp。

Вариант №3: метод Шелла; размеры массивов 2000, 5000, 6800.
第3变体：希尔排序；数组长度为 2000、5000、6800。

Вариант №8: простая вставка; размеры массивов 1200, 2000, 7500.
第8变体：直接插入排序；数组长度为 1200、2000、7500。

Программа последовательно выполняет оба варианта, измеряет
время сортировки и проверяет правильность результата.
程序在一次运行中依次完成两个变体，测量排序时间，并检查排序是否正确。

Компиляция / 编译（C++17）:
g++ -std=c++17 -O2 lab1_part1.cpp -o lab1_part1

Запуск / 运行:
Windows: lab1_part1.exe
Linux/macOS: ./lab1_part1

sorted=YES означает, что массив отсортирован по возрастанию.
sorted=YES 表示数组已经正确按升序排序。

Важно / 重要说明:
Методические указания также требуют исследования в Sort_new.exe
и Winsort.exe с заполнением экспериментальных таблиц.
Это отдельная часть работы, не выполненная данным исходным кодом.
老师的 PDF 还要求使用 Sort_new.exe 和 Winsort.exe 进行实验并填写测量表。
本 C++ 程序不代替这些软件的测量结果，相关实验尚未完成。

Вывод / 结论:
Метод Шелла сортирует элементы с постепенно уменьшающимся шагом.
Простая вставка вставляет каждый следующий элемент в уже
отсортированную часть массива.
希尔排序通过逐渐减小间隔进行排序；直接插入排序把新元素插入到
前面已经排好序的部分。程序可以检查两种排序结果的正确性。
