Лабораторная работа №1 — единый C++17 файл lab1_all.cpp.
Откройте один проект Visual Studio, добавьте только lab1_all.cpp, выберите стандарт C++17 и запустите Ctrl+F5.
Меню: 1 — SORT №3; 2 — SORT №8; 3 — POISK №3; 4 — POISK №8; 5 — все задания; 0 — выход.
После выполнения создаются четыре CSV-файла с результатами измерений.
Сравнения и перемещения подсчитываются для сортировки. Данные измерений необходимо получать на компьютере студента.
Точное соответствие алгоритмов POISK таблице вариантов требуется подтвердить по исходному заданию.
