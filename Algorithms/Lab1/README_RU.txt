ЛАБОРАТОРНАЯ РАБОТА №1 — ЧАСТЬ 1 / 实验1 第一部分
================================================
Два отдельных исходных файла / 两个独立 C++ 程序

1. variant3_shell.cpp — Вариант №3: метод Шелла.
   第3变体：希尔排序；N = 2000, 5000, 6800。
2. variant8_insertion.cpp — Вариант №8: простая вставка.
   第8变体：简单插入排序；N = 1200, 2000, 7500。

В каждом файле реализованы семь методов сортировки для сравнительного
исследования: простая вставка, слияние, Шелл, простой выбор, Хоар,
бинарная вставка, шейкерная сортировка.
每个文件还实现了7种排序方法用于比较研究：直接插入、归并、
希尔、选择、快速、二分插入、鸡尾酒排序。
Индивидуальный метод указан в названии каждого файла.
每个变体的指定算法已单独实现。

Исследуются три исходных порядка: случайный, возрастающий и убывающий.
测试随机、升序、降序三种初始数组状态。
Фиксируются время (мс), сравнения, перемещения и корректность.
记录运行时间（毫秒）、比较次数、移动次数以及正确性。
Результаты записываются в variant3_results.csv / variant8_results.csv.
结果分别写入对应 CSV 文件，便于制作实验表格。

Компиляция / 编译（C++17）:
g++ -std=c++17 -O2 variant3_shell.cpp -o variant3_shell
g++ -std=c++17 -O2 variant8_insertion.cpp -o variant8_insertion

Запуск / 运行：
Windows: variant3_shell.exe  /  variant8_insertion.exe
Linux/macOS: ./variant3_shell  /  ./variant8_insertion

Проверка / 检查:
При запуске выполняются автоматические проверки пустого массива,
одного элемента, дубликатов и неупорядоченного массива.
程序启动时自动检查空数组、单元素、重复值和乱序数组。
В каждой строке correct=YES означает совпадение с std::sort.
CSV 中 correct=YES 表示排序结果与标准排序一致。
Замеры зависят от компьютера; время измеряется при запуске.
运行时间取决于电脑，测量值必须以实际运行结果为准。

Вывод / 结论：
Метод Шелла уменьшает шаг между сравниваемыми элементами;
простая вставка помещает очередной элемент в отсортированную часть.
希尔排序逐渐缩小比较间隔；直接插入排序把元素插入已排序部分。
