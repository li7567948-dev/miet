# Лабораторная работа №1 — Часть 1 / 实验1 第一部分

Источник задания: «Лабораторная работа №1.pdf», страницы 2–5.
任务依据：老师 PDF 第2–5页，分别编写对应变体的排序算法。

- Вариант 3: метод Шелла, N=2000, 5000, 6800.
- Вариант 8: простая вставка, N=1200, 2000, 7500.

## Проекты / 两个独立项目
Каждый файл содержит собственную функцию main(). **Не добавляйте оба файла в один проект Visual Studio.**
每个源文件都包含自己的 main()。必须在 Visual Studio 建立两个独立项目，不能把两个 .cpp 一起放进同一个项目编译。

Создайте два проекта «Консольное приложение (C++)»: Lab1_Variant3 и Lab1_Variant8. В первом проекте оставьте только variant3_shell.cpp; во втором — только variant8_insertion.cpp. Если Visual Studio создала пример с main(), исключите его из проекта.
创建两个 C++ 控制台项目，每个项目仅保留对应 cpp。如果模板自动生成了含 main() 的示例源文件，请将它从项目中排除。

Компиляция / 编译 (C++17):
```
g++ -std=c++17 -O2 variant3_shell.cpp -o variant3_shell
g++ -std=c++17 -O2 variant8_insertion.cpp -o variant8_insertion
```

## Эксперименты / 实验
Программы выполняют по 5 запусков для каждого заданного размера массива, для случайного, уже упорядоченного и обратно упорядоченного массива. Проверяют результат сравнением с std::sort, выводят время, количество сравнений и перемещений, средние значения и CSV.
程序对每个指定长度分别测试随机、升序、逆序数组，每种测试5次；输出时间、比较次数、移动次数、平均值，并保存 CSV；通过标准排序结果验证正确性。

Время измеряется только для собственного алгоритма. Генерация данных, std::sort для проверки и запись в CSV не входят в измерение.
计时仅包括自编排序算法，不包含数据生成、正确性检查和文件写入。
