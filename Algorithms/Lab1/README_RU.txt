Исходные файлы / 源代码:
variant3_shell.cpp
variant8_insertion.cpp

Каждый файл имеет свою функцию main().
每个源文件都有独立的 main()，请在 Visual Studio 中分别创建两个项目。
不要在同一个项目中同时编译这两个文件，否则会发生重复定义链接错误。

C++17:
g++ -std=c++17 -O2 variant3_shell.cpp -o variant3_shell
g++ -std=c++17 -O2 variant8_insertion.cpp -o variant8_insertion

Программа сортирует случайный массив и измеряет время выполнения.
程序生成随机数组、排序、测量运行时间并验证排序结果。
