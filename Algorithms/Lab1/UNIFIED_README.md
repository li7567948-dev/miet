# Lab 1 — unified C++17 source

Use **only `lab1_all.cpp`** in one Visual Studio C++17 console project. There is exactly one `main()`.

Menu options: 1 = SORT 3 (Shell), 2 = SORT 8 (insertion), 3 = POISK 3 (digit trie), 4 = POISK 8 (hash lookup), 5 = all, 0 = exit.

Sorting runs 5 trials per N and input order (random, ascending, descending), logs time in microseconds, comparisons, moves, and correctness. Search runs present/absent trials. CSV results are generated when the program is executed.

The exact POISK variant mapping remains to be confirmed against the original search assignment. No measurements are fabricated.
